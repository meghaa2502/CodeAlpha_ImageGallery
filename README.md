# Responsive Image Gallery

## Description
A responsive image gallery built using HTML, CSS, and JavaScript. The gallery allows users to browse images with category filters, view images in a lightbox, and enjoy a clean dark-themed user interface.

## Features
- Responsive design
- Category-based image filtering
- Lightbox image preview
- Smooth animations and transitions
- Dark-themed UI
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
